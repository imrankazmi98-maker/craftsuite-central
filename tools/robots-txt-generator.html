Robots.txt Generator

Create a valid robots.txt file for your website in seconds.

User-agent: *
Allow: /

Why use this tool?

A correct robots.txt file tells search engine crawlers which parts of your site to crawl and which to skip, helping you avoid wasting crawl budget on admin pages, staging folders or duplicate content while making sure your important pages and sitemap are easy to find.

How to use the Robots.txt Generator

  1. Set the User-Agent (use * for all crawlers).
  2. Set the Allow directive and optionally add your sitemap URL.
  3. Click Create Robots.txt, copy the output and upload it as robots.txt at your site root.

Frequently Asked Questions

Where should robots.txt be placed?

At the root of your domain, e.g. https://example.com/robots.txt.

Does robots.txt block a page from Google entirely?

It only discourages crawling; use a noindex meta tag to prevent a page from being indexed.

Can I block a specific folder only?

Yes, add a Disallow line manually after generating the base file, e.g. 'Disallow: /admin/'.

Do I need one robots.txt for each subdomain?

Yes, robots.txt only applies to the exact host it's served from, so each subdomain needs its own file if you want different rules.
