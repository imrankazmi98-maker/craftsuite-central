HTML Encoder / Decoder

Escape HTML special characters to entities, or decode HTML entities back to plain text.

Why use this tool?

HTML encoding prevents raw code snippets or user-submitted text from being interpreted as markup - useful when displaying example code on a blog or safely rendering text that contains angle brackets or ampersands.

How to use the HTML Encoder / Decoder

  1. Paste your HTML or text.
  2. Click Encode to convert special characters to entities, or Decode to reverse.
  3. Copy the result.

Frequently Asked Questions

Which characters get encoded?

The core five: &, <, >, " and '.

Is this a substitute for proper output sanitisation in an app?

No, for security-sensitive rendering use your framework's built-in escaping; this tool is for quick manual conversions.
