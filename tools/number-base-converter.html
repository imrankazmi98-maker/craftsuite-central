Why use this tool?

Programmers regularly move between number bases: reading a hex color code, debugging bitwise flags in binary, or working with octal file permissions on Unix systems. This one tool replaces separate binary-to-hex, hex-to-decimal and octal converters.

How to use the Number Base Converter

  1. Type your number into the input field.
  2. Select which base that number is currently in.
  3. All four equivalents update instantly below.

Frequently Asked Questions

What characters are valid for hexadecimal input?

Digits 0-9 and letters A-F (case-insensitive).

Does it support negative numbers?

No, this tool works with non-negative integers only.
