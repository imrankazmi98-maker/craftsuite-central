Base64 Encoder / Decoder

Encode text to Base64 or decode Base64 back to plain text, instantly and privately.

Why use this tool?

Base64 encoding is widely used to embed small images directly in CSS or HTML (data URIs), to safely transmit binary data inside JSON or XML, and to encode authentication tokens. Decoding is just as common when inspecting a JWT payload or debugging an API that returns encoded fields.

How to use the Base64 Encoder / Decoder

  1. Type or paste your text or Base64 code into the left box.
  2. Click Encode or Decode as needed.
  3. Copy the result from the right box.

Frequently Asked Questions

What is Base64 used for?

It is commonly used to embed binary data like images or files as text, e.g. inside CSS or JSON.

Does this support Unicode text?

Yes, the tool safely handles UTF-8 characters when encoding and decoding.

Is Base64 encoding the same as encryption?

No. Base64 only changes the representation of data - it provides no security or confidentiality, and anyone can decode it instantly.

Can I encode an entire file, not just text?

This tool encodes typed or pasted text; for binary files, use a dedicated file-to-Base64 converter.
