Why use this tool?

Your public IP is useful for setting up remote access, whitelisting your connection on a server firewall, troubleshooting network issues, or just checking which IP a website sees you as.

How to use the What Is My IP

  1. The page automatically looks up and displays your public IP.
  2. Click Refresh if you've reconnected to a different network.

Frequently Asked Questions

Is this my private/local IP?

No, this shows your public-facing IP as seen by the internet, not your local network address (like 192.168.x.x).

Does this tool store my IP?

No, the lookup happens directly between your browser and a public IP lookup service; this site does not log or store it.
