URL Encoder / Decoder

Encode text for safe use in a URL, or decode a percent-encoded URL back to plain text.

Why use this tool?

URL encoding is required whenever a query string contains spaces, special characters or non-Latin text - for example passing a search phrase or an email address as a URL parameter without breaking the link.

How to use the URL Encoder / Decoder

  1. Paste your text or full URL.
  2. Click Encode to percent-encode special characters, or Decode to reverse it.
  3. Copy the result.

Frequently Asked Questions

What's the difference between encodeURIComponent and encodeURI?

This tool uses encodeURIComponent, which also escapes characters like & and = - ideal for encoding individual query parameter values.
