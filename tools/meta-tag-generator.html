Why use this tool?

Meta tags are the first thing search engines and social platforms read about your page. A well-written title and description directly influence click-through rate from search results, while OpenGraph and Twitter Card tags control how a link looks when shared on Facebook, LinkedIn or X.

How to use the Meta Tag & OpenGraph Generator

  1. Fill in the title, description, canonical URL, keywords and OG image.
  2. Click Generate Tags to build the HTML snippet.
  3. Copy the code and paste it inside your page's <head> section.

Frequently Asked Questions

What is an OG image used for?

It is the preview image shown when your page is shared on Facebook, LinkedIn or other platforms.

Do I need Twitter Card tags too?

Yes if you want a rich preview when the page is shared on X/Twitter; this tool generates both.

What's the ideal length for a meta description?

Aim for under 155-160 characters so Google doesn't truncate it in search results.

Do I need separate Twitter Card tags if I already have OpenGraph tags?

Twitter/X can fall back to OpenGraph tags, but adding dedicated Twitter Card tags gives you more reliable control over that preview.
